# Участие в проекте

Это небольшой домашний проект, но pull request'ы и issue приветствуются.

## Перед отправкой изменений

```bash
npm install
npm run typecheck
npm run lint
npm test
npm run build
```

Если меняли что-то, связанное с базой или webhook, прогоните ещё и e2e
(нужны локальные Postgres с базой `alice_test` и Redis):

```bash
npm run test:e2e
```

## Соглашения

- Строгий TypeScript: без `any`, `@ts-ignore` и отключения правил линтера без
  объяснения прямо в коде.
- Бизнес-логика живёт в сервисах, контроллеры остаются тонкими.
- Работа с beta Agents API идёт только через `AiConversationProvider` —
  так переезд на следующую версию API затрагивает один файл.
- Изменения схемы — только миграциями (`synchronize` выключен намеренно).
- Комментарии объясняют «почему», а не пересказывают код.

## Что особенно полезно

- Реализация долговременной памяти поверх `MemoryService`.
- Локальные инструменты для `ToolRegistryService` (умный дом, календарь, погода).
- Обслуживание старых Agent Session.
